# Panini8 Admin Panel

A secure admin dashboard for managing learning paths, built with Next.js, MongoDB, and Tailwind CSS.


## Features

- 🔐 **Role-based authentication** (Admin-only access)
- 📚 **Learning path management**:
  - Create Goals → Courses → Topics hierarchy
  - Assign learning paths to users
- 📱 **Mobile-responsive UI**
- 🔄 **Real-time data operations** with MongoDB

## Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: MongoDB
- **Authentication**: JWT with HTTP-only cookies

## Setup Instructions

### 1. Prerequisites

- Node.js v18+
- MongoDB Atlas account or local MongoDB instance
- Git (optional)
